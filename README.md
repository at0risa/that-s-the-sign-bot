# That's The Sign Bot ✨

A simple Telegram bot that sends supportive messages and small signs of encouragement.

## Features

- `/start` — introduces the bot
- `/message` — sends a random supportive message
- `/help` — shows available commands
- Messages are stored in a JSON file
- Bot token is stored securely in `.env`

## Tech Stack

- Python
- python-telegram-bot
- python-dotenv
- JSON
- Git / GitHub
